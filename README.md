# TekNovaOS
TekNova OS es un sistema operativo simulado hecho completamente con HTML, CSS y JavaScript. Incluye múltiples aplicaciones integradas como una calculadora, reloj, navegador simulado, clima con geolocalización, explorador de archivos, bloc de notas, consola y ajustes personalizados. Ideal para fines educativos, experimentación web o demostraciones interactivas.
